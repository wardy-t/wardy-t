# Hi, I'm Tom Ward 👋

I'm a software engineer who came to the field through a career change and the General Assembly bootcamp. The stack I started with was React, Python and JavaScript. More recently, I've been focusing on Kotlin, Spring Boot and Java, particularly backend APIs.

I enjoy taking a practical problem and building something useful around it, from customer-facing websites and full-stack applications to backend services with clear, testable rules.

## Featured projects

- **[TripMatch](https://github.com/wardy-t/tripmatch)** — A Kotlin and Spring Boot API that ranks travel destinations against a traveller's budget, climate preferences, interests and maximum flight time. Built with PostgreSQL, Docker and automated tests.

- **[MemberShield](https://github.com/wardy-t/membershield)** — A payment-risk assessment application designed to explore how banks can identify potentially risky transfers while giving customers clear reasons for additional checks. It uses Kotlin and Spring Boot, with deterministic rules designed to make decisions testable and explainable.

- **[Just Eat Assignment](https://github.com/wardy-t/just-eat-assignment)** — A React app for finding restaurants by UK postcode, with cuisine filters, sorting and a map view using the Just Eat Takeaway API.
